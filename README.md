# 💼 Real-World Projects

## 🥋 Pusaka Rinjani

### Event Management System for Pencak Silat Competition

A web-based application designed to support the operational workflow of **pencak silat competitions** and event organizers.

The system is built to serve different users involved in a competition, including event administrators, judges, and competition officials.

### Key Features

* 🎪 Event management
* 🏟️ Match / arena management
* 👤 Role-based access
* 🧑‍⚖️ Judge scoring interface
* 📊 Score recap
* 🥇 Match results
* 📋 Competition administration
* 🔐 Access through unique arena/session codes

The project is an opportunity to apply full-stack development concepts to a real operational environment, particularly around **data relationships, user roles, scoring workflows, and system architecture**.

**Focus:**
`Full-Stack Development` `Event Management` `Scoring System` `Database Design` `Role-Based Access` `REST API`
